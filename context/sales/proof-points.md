# Saporo proof points

The only Saporo numbers an article may cite (D51). Each needs a
**methodology** line before it can be used: a model cites
"5.9M+ attack paths identified across customer environments (Saporo platform
data, 2026)", and it ignores "millions of attack paths".

Set **Citable** to `yes` once the methodology is filled in and the number is
approved for public use. The audit fails an article that uses a number marked
`no`, and warns on a Saporo number that isn't in this table at all.

Edit this file in Admin → Context. Changes apply from the next article run.
